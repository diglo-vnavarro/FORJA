# Proyecto Iker

Proyecto Iker es el primer caso práctico de aplicación de FORJA en un entorno deportivo formativo real.

## Contexto

El caso documenta la preparación física de un futbolista sub-14 durante su ventana de crecimiento rápido acelerado (Circa-PHV) previa a la pretemporada.

## Documentos del caso

- [Memoria técnica del caso](caso-iker.md): Evaluación de competencia motriz según [EVAL-001](../../docs/08-assessments/eval-001-initial-movement-competence.md), prescripción basada en [SES-001](../../docs/06-sessions/ses-001-initial-strength-and-movement-learning.md) y [SES-002](../../docs/06-sessions/ses-002-general-strength.md), y criterios de parada.
- `iker-perfil-export.json`: Ficha exportable de datos locales bajo la directiva [D-021](../../docs/00-project/decisions.md#d-021--privacidad-y-gobernanza-de-datos-de-deportistas-menores-de-edad-dec-d) directamente importable en el módulo de Atletas de la aplicación.

## Separación respecto a la metodología

Los datos y decisiones individuales de este caso pertenecen exclusivamente a esta carpeta y no constituyen prescripción generalizada para otros deportistas. Cualquier principio metodológico general derivado debe integrarse en `docs/` tras la correspondiente revisión editorial.
