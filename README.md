# FORJA

FORJA es un sistema de conocimiento y toma de decisiones para el desarrollo físico de jóvenes deportistas.

Su propósito es transformar evidencia científica, principios de entrenamiento y experiencia práctica contrastada en criterios claros para diseñar, adaptar y evaluar programas de desarrollo físico a largo plazo.

## Estado del proyecto

FORJA se encuentra actualmente en fase fundacional.

La metodología, sus fundamentos científicos y sus aplicaciones prácticas están en proceso de investigación, redacción y revisión.

El contenido de este repositorio no sustituye la valoración individual de profesionales sanitarios, preparadores físicos cualificados o especialistas en ciencias del deporte.

## Primera aplicación

[Proyecto Iker](examples/proyecto-iker/README.md) será el primer caso práctico de FORJA: la preparación física previa a la pretemporada de un futbolista sub-14.

La información personal del deportista se mantendrá fuera de la metodología general y se utilizará únicamente para validar su aplicación práctica.
