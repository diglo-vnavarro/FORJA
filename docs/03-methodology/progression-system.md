# Sistema de progresión FORJA

## Propósito

Definir cómo decide FORJA si una tarea debe:

- mantenerse;
- progresarse;
- simplificarse;
- modificarse;
- sustituirse;
- reducirse;
- aumentarse.

[MET-001](initial-athlete-assessment.md) responde:

> **¿Desde dónde empieza el deportista?**

MET-002 responde:

> **¿Cuál es el siguiente paso apropiado?**

La progresión no dependerá únicamente del calendario, la edad, el número de sesiones realizadas ni del peso utilizado.

FORJA progresará cuando exista una razón para aumentar el estímulo y el deportista muestre competencia y tolerancia suficientes para hacerlo.

---

# 1. Principio fundamental

FORJA utilizará este ciclo:

> **observar → interpretar → decidir → aplicar → volver a observar**

Una progresión nunca será definitiva.

Cada decisión genera nueva información.

Por tanto, el sistema no funciona como una escalera que únicamente permite subir.

Puede avanzar, mantenerse o retroceder temporalmente.

---

# 2. Qué significa progresar

Progresar no significa necesariamente realizar un ejercicio más difícil.

Significa modificar el entrenamiento de forma que el estímulo siga siendo apropiado para el objetivo y el deportista.

Podemos progresar mediante:

- carga;
- volumen;
- velocidad;
- amplitud;
- complejidad;
- estabilidad;
- unilateralidad;
- dirección;
- incertidumbre;
- densidad;
- frecuencia;
- autonomía.

Por tanto:

> **añadir peso es solo una forma de progresar.**

---

# 3. La progresión necesita un objetivo

Antes de modificar una tarea debemos responder:

> **¿Qué queremos mejorar?**

Por ejemplo, en una sentadilla podríamos querer desarrollar:

- aprendizaje técnico;
- [fuerza](../02-science/youth-strength-training.md);
- control;
- rango;
- velocidad de ejecución;
- potencia.

Una modificación puede ser progresión para un objetivo y mala decisión para otro.

Añadir carga puede ser apropiado para desarrollar fuerza.

Puede ser innecesario si el objetivo actual es aprender una nueva posición.

Por tanto:

> **FORJA no progresará ejercicios. Progresará objetivos mediante tareas.**

---

# 4. Los tres estados de competencia

[MET-001](initial-athlete-assessment.md) introdujo tres estados.

### A — Competencia suficiente

El deportista resuelve la tarea con control suficiente para el objetivo y la demanda actuales.

### B — Competencia parcial

El deportista puede realizar la tarea, pero existen dificultades relevantes que justifican aprendizaje, reducción de demanda o mayor supervisión.

### C — Competencia insuficiente

La demanda actual impide resolver adecuadamente la tarea.

Debe utilizarse una variante más apropiada.

Estos estados no representan la calidad global del deportista.

Se aplican a:

> **una tarea determinada bajo unas condiciones determinadas.**

---

# 5. Competencia suficiente no significa perfección

FORJA no esperará una ejecución ideal antes de progresar.

Para considerar una tarea suficientemente competente buscaremos, según el contexto:

- comprensión;
- control;
- repetibilidad razonable;
- autonomía;
- tolerancia;
- mantenimiento de los aspectos importantes de la tarea.

Pequeñas diferencias entre repeticiones son normales.

La pregunta no será:

> ¿Ha sido perfecto?

Sino:

> **¿Tiene suficiente competencia para aumentar razonablemente la demanda?**

---

# 6. Las cinco variables de decisión

Antes de progresar, FORJA observará cinco dimensiones.

### 1. Competencia

¿Puede resolver la tarea?

### 2. Calidad

¿Mantiene los elementos relevantes cuando la repite?

### 3. Tolerancia

¿La carga es bien tolerada?

### 4. Objetivo

¿La tarea sigue produciendo el estímulo que buscamos?

### 5. Contexto

¿Es apropiado progresar teniendo en cuenta la carga total y situación actual?

Ninguna dimensión funciona completamente aislada.

---

# 7. La matriz básica FORJA

Conceptualmente:

| Competencia | Tolerancia | Estímulo | Decisión probable |
|---|---|---|---|
| suficiente | buena | insuficiente | progresar |
| suficiente | buena | adecuado | mantener |
| suficiente | mala | adecuado/alto | reducir dosis o modificar |
| parcial | buena | adecuado | practicar o simplificar |
| parcial | mala | alto | regresar |
| insuficiente | cualquiera | cualquiera | regresar o sustituir |

Esta tabla representa lógica.

No constituye un algoritmo automático definitivo.

El entrenador sigue interpretando el contexto.

---

# 8. Mantener

Mantener una tarea es una decisión válida.

No progresar cada semana no significa estancarse.

Puede ser apropiado mantener cuando:

- el estímulo sigue siendo suficiente;
- el deportista continúa aprendiendo;
- la ejecución aún gana estabilidad;
- existe otra carga deportiva importante;
- no necesitamos mayor dificultad;
- queremos consolidar.

FORJA evitará progresar únicamente para que el programa parezca novedoso.

> **Si funciona, no necesitamos cambiarlo porque sí.**

---

# 9. Progresar

Una progresión será apropiada cuando:

- exista competencia suficiente;
- la tarea sea bien tolerada;
- el estímulo actual haya dejado de ser suficiente;
- aumentar la demanda ayude al objetivo;
- el contexto permita absorber la nueva carga.

No es obligatorio cumplir todos estos criterios de forma matemática.

Representan el razonamiento que debe existir antes de progresar.

---

# 10. Regresar

Una regresión reduce una o varias demandas para facilitar:

- aprendizaje;
- control;
- tolerancia;
- recuperación;
- confianza.

Puede utilizarse cuando:

- la competencia es insuficiente;
- la técnica se deteriora de forma relevante;
- aumenta excesivamente la fatiga;
- aparece una nueva dificultad;
- cambia el contexto;
- existe un periodo de crecimiento rápido;
- se introduce una capacidad nueva.

Como establecimos en [SCI-003](../02-science/motor-learning-and-competence.md):

> **regresar no es fracasar.**

Es adaptar la tarea al punto actual.

---

# 11. Sustituir

No todas las dificultades deben resolverse mediante regresiones del mismo ejercicio.

A veces es mejor utilizar otra tarea que persiga el mismo objetivo.

Por ejemplo:

si una determinada variante de sentadilla genera dificultades que impiden trabajar fuerza adecuadamente, puede utilizarse otra variante que permita producir un estímulo equivalente.

FORJA no estará casado con ejercicios.

> **El objetivo tiene prioridad sobre el ejercicio.**

---

# 12. Aumentar carga

La carga externa aumentará cuando:

- la técnica sea suficientemente competente;
- el deportista tolere la tarea;
- la resistencia actual ya no produzca el estímulo necesario;
- el aumento sea compatible con el objetivo.

No se utilizarán incrementos automáticos por calendario.

FORJA tampoco establecerá una regla universal como:

> +5 kg cada semana.

La magnitud del aumento dependerá del ejercicio, material y deportista.

---

# 13. Aumentar volumen

Podemos aumentar:

- repeticiones;
- series;
- distancia;
- tiempo;
- contactos.

Pero volumen adicional tiene un coste.

FORJA preguntará:

> **¿Necesitamos realmente más?**

Si el mismo estímulo puede conseguirse con menos trabajo, aumentar volumen no es automáticamente una mejora.

Esto conecta con [SCI-005](../02-science/youth-load-fatigue-recovery.md):

> **mínima dosis suficiente.**

---

# 14. Aumentar velocidad

En determinadas tareas, progresar puede significar ejecutar más rápido.

Por ejemplo:

- [sprint](../02-science/youth-speed-development.md);
- lanzamiento;
- salto;
- movimientos de potencia.

Esto modifica considerablemente la demanda.

La velocidad no se aumentará antes de que exista competencia suficiente para controlar la tarea.

---

# 15. Aumentar rango

Una progresión también puede consistir en ampliar el rango de movimiento.

Por ejemplo:

- sentadilla más profunda;
- zancada con mayor recorrido;
- desplazamiento más largo.

Mayor rango no significa automáticamente mejor ejercicio.

Debe contribuir al objetivo y ser apropiado para el deportista.

---

# 16. Aumentar complejidad

Podemos aumentar complejidad mediante:

- más grados de libertad;
- cambios de dirección;
- coordinación adicional;
- nuevas posiciones;
- múltiples tareas simultáneas.

Pero complejidad no es sinónimo de calidad.

FORJA evitará ejercicios innecesariamente complicados.

> **La complejidad solo progresa cuando aporta valor.**

---

# 17. Aumentar incertidumbre

En tareas perceptivo-decisionales podemos progresar desde:

- solución conocida;
- pocas alternativas;
- señal tardía;
- estímulo simple;
- múltiples opciones;
- contexto deportivo real.

Esto será especialmente relevante en agilidad.

Como establecimos en [SCI-007](../02-science/youth-change-of-direction-agility.md):

> **competencia antes que incertidumbre.**

---

# 18. Bilateral y unilateral

Pasar de bilateral a unilateral puede aumentar determinadas demandas.

Pero no representa una progresión universal.

Un ejercicio unilateral puede ser más sencillo que otro bilateral dependiendo de:

- carga;
- soporte;
- rango;
- estabilidad;
- técnica.

FORJA no utilizará:

> bilateral → unilateral

como regla automática de niveles.

---

# 19. Estabilidad

Reducir estabilidad puede aumentar dificultad.

Sin embargo, más inestabilidad no significa automáticamente mejor entrenamiento.

Si el objetivo es producir mucha fuerza, una superficie excesivamente inestable puede dificultarlo.

Por tanto:

> **la variable de progresión debe ser compatible con el objetivo.**

---

# 20. Fatiga como criterio de parada

En tareas donde la calidad sea prioritaria, FORJA podrá finalizar un bloque cuando aparezca:

- deterioro técnico relevante;
- reducción clara de velocidad;
- pérdida de control;
- caída de intención;
- fatiga incompatible con el objetivo.

No necesitamos llegar al fallo.

Esto aplica especialmente a:

- velocidad;
- [potencia](../02-science/youth-power-and-plyometrics.md);
- aprendizaje;
- determinados ejercicios de fuerza.

---

# 21. Dolor como señal diferente

La fatiga puede justificar ajustar dosis.

El dolor puede requerir otra decisión.

Cuando aparezca:

- dolor significativo;
- dolor creciente;
- dolor localizado persistente;
- dolor que modifica el movimiento;

FORJA no utilizará la progresión como experimento.

Se detendrá o modificará la tarea y se actuará según corresponda.

---

# 22. El contexto puede impedir una progresión correcta

Un deportista puede estar preparado técnicamente para progresar pero encontrarse en una semana con:

- partido importante;
- entrenamiento adicional;
- mala recuperación;
- [crecimiento acelerado](../02-science/growth-and-maturation.md);
- estrés;
- fatiga.

FORJA podrá mantener temporalmente la carga.

> **Preparado para progresar no significa obligado a progresar hoy.**

---

# 23. Progresión técnica y progresión física

Podemos progresar dos dimensiones distintas.

### Técnica

Mayor autonomía, control o complejidad.

### Física

Mayor fuerza, velocidad, volumen o potencia.

No siempre deben progresar simultáneamente.

Por ejemplo:

podemos mantener la misma variante técnica y aumentar ligeramente resistencia.

O mantener carga y aumentar autonomía.

Esto permitirá construir progresiones más precisas.

---

# 24. Cambiar una sola variable

Cuando sea posible, FORJA preferirá modificar pocas variables simultáneamente.

Si aumentamos al mismo tiempo:

- carga;
- rango;
- velocidad;
- volumen;
- complejidad;

resultará difícil saber qué provocó la respuesta.

Por tanto:

> **progresar poco a poco mejora nuestra capacidad para interpretar.**

No será una regla absoluta, pero sí una preferencia metodológica.

---

# 25. Microprogresiones

No todas las progresiones necesitan ser grandes.

Ejemplos:

- una repetición más;
- ligeramente más carga;
- unos metros adicionales;
- menor asistencia;
- mejor rango;
- una decisión adicional;
- menor descanso cuando el objetivo lo justifica.

Pequeños cambios permiten mantener continuidad.

FORJA favorecerá progresiones que el deportista pueda absorber.

---

# 26. Regresión temporal por contexto

Un deportista puede realizar normalmente un nivel avanzado y utilizar temporalmente una variante inferior.

Por ejemplo:

- después de enfermedad;
- después de vacaciones;
- tras una semana competitiva muy exigente;
- durante readaptación;
- después de una fase sin practicar una habilidad.

Esto no modifica necesariamente su nivel histórico.

Describe el estado actual.

---

# 27. Nivel no es identidad

FORJA evitará decir:

> este jugador es nivel 2.

Preferiremos:

> actualmente utiliza nivel 2 en esta progresión.

La diferencia es importante.

El nivel pertenece a:

- capacidad;
- tarea;
- contexto.

No a la persona completa.

Esto mantiene coherencia con [MET-001](initial-athlete-assessment.md).

---

# 28. Una progresión puede tener ramas

No todas las progresiones deben ser lineales.

Por ejemplo, después de una sentadilla básica un deportista podría progresar hacia:

- mayor carga;
- unilateralidad;
- potencia;
- rango;
- otra variante.

La elección depende del objetivo.

Por tanto, la futura biblioteca FORJA utilizará:

> **redes de progresión**

más que escaleras universales.

---

# 29. Requisitos previos

Algunas tareas sí necesitarán requisitos.

Por ejemplo, una tarea reactiva compleja puede requerir competencia básica en:

- aterrizar;
- frenar;
- cambiar dirección.

Pero FORJA evitará listas arbitrarias excesivas.

Un requisito debe existir porque la siguiente tarea realmente lo necesita.

---

# 30. El criterio de progreso pertenece al ejercicio

Cada ficha de ejercicio futura deberá incluir:

- objetivo;
- requisitos;
- indicadores de competencia;
- progresiones;
- regresiones;
- señales de parada;
- variables de carga.

Así la biblioteca no será una lista de ejercicios.

Será una biblioteca de decisiones.

---

# 31. Decisión automática frente a decisión asistida

FORJA podrá automatizar algunas recomendaciones en el futuro.

Por ejemplo:

si:

- competencia = insuficiente;
- tarea = avanzada;

entonces:

> sugerir una regresión.

Pero el sistema no debe fingir que todo puede decidirse automáticamente.

Existirán decisiones donde el entrenador deberá interpretar:

- contexto;
- calidad;
- objetivos;
- historial;
- información incompleta.

Por tanto, la futura aplicación será:

> **un sistema de apoyo a decisiones**

y no un sustituto automático del entrenador.

---

# 32. Motor conceptual de progresión

La lógica general será:

### Paso 1 — Seguridad

¿Existe alguna señal que impida continuar?

Si sí:

> detener, modificar o derivar.

### Paso 2 — Competencia

¿Puede resolver la tarea?

- suficiente;
- parcial;
- insuficiente.

### Paso 3 — Tolerancia

¿Cómo responde a la carga?

### Paso 4 — Estímulo

¿La tarea sigue siendo suficiente para el objetivo?

### Paso 5 — Contexto

¿Es apropiado aumentar demanda ahora?

### Paso 6 — Decisión

- mantener;
- progresar;
- simplificar;
- reducir dosis;
- sustituir;
- detener.

### Paso 7 — Reevaluar

Observar la respuesta a la decisión.

---

# 33. Semáforo de progresión

Como modelo conceptual:

### Verde

Competencia suficiente + buena tolerancia.

Puede:

- mantenerse;
- o progresarse si el estímulo lo requiere.

### Ámbar

Competencia parcial, fatiga relevante o dudas de tolerancia.

Puede:

- mantenerse;
- simplificarse;
- reducir dosis;
- aumentar supervisión.

### Rojo

Competencia insuficiente o señal relevante de seguridad.

Debe:

- regresarse;
- sustituirse;
- detenerse;

según el motivo.

Este semáforo no constituye todavía un algoritmo clínico.

Es una herramienta de razonamiento.

---

# 34. Ejemplo: sentadilla

Un joven realiza:

**3 × 8 sentadillas con 8 kg.**

Observamos:

- competencia suficiente;
- control estable;
- RPE moderado;
- buena recuperación;
- objetivo actual: fuerza.

La sesión siguiente no tiene por qué cambiar.

Pero después de varias exposiciones observamos que:

- RPE disminuye;
- la ejecución sigue estable;
- la carga se tolera bien.

Podemos aumentar ligeramente resistencia.

---

Otro joven realiza la misma tarea.

Observamos:

- pérdida importante de control en las últimas repeticiones;
- RPE muy elevado;
- dificultad para mantener rango.

La decisión no será:

> tiene que acostumbrarse.

Puede ser:

- reducir repeticiones;
- reducir carga;
- utilizar otra variante.

Mismo ejercicio.

Decisión diferente.

---

# 35. Ejemplo: velocidad

Un joven realiza sprints de 15 metros.

Las primeras repeticiones muestran:

- intención alta;
- buena calidad.

Después:

- disminuye claramente la velocidad;
- aumenta la fatiga;
- pierde calidad de aceleración.

Si el objetivo es velocidad:

> terminar el bloque puede ser la progresión correcta del proceso.

Añadir más repeticiones no mejora necesariamente la sesión.

---

# 36. Ejemplo: agilidad

Un jugador controla adecuadamente un cambio preplanificado de 45 grados.

Podemos progresar añadiendo:

- dos direcciones posibles;
- señal tardía.

Si pierde completamente control:

no significa que no pueda entrenar agilidad.

Significa que la progresión introdujo demasiada incertidumbre.

Podemos reducirla.

---

# 37. Errores frecuentes

### Progresar por calendario

**Error:** cambiar automáticamente cada dos semanas.

**FORJA:** progresar según respuesta.

### Progresar siempre aumentando carga

**Error:** asociar progreso únicamente con kilos.

**FORJA:** utilizar múltiples variables.

### Buscar ejercicios más difíciles

**Error:** confundir complejidad con calidad.

**FORJA:** seleccionar demanda según objetivo.

### No mantener nunca

**Error:** cambiar continuamente para generar variedad.

**FORJA:** consolidar cuando sea útil.

### No regresar

**Error:** interpretar una regresión como fracaso.

**FORJA:** utilizarla cuando mejora aprendizaje o tolerancia.

### Progresar muchas variables simultáneamente

**Error:** aumentar carga, rango y volumen a la vez sin necesidad.

**FORJA:** preferir cambios interpretables.

### Ignorar contexto

**Error:** progresar porque la técnica lo permite aunque el deportista llegue muy fatigado.

**FORJA:** considerar carga total.

### Convertir niveles en etiquetas

**Error:** llamar al deportista principiante o avanzado globalmente.

**FORJA:** el nivel pertenece a una tarea y contexto.

---

# 38. Decisiones FORJA

### F-PROG-001 — La progresión responde a un objetivo

No se modificará una tarea sin conocer qué queremos desarrollar.

### F-PROG-002 — Competencia suficiente precede al aumento de demanda

No se exigirá perfección.

### F-PROG-003 — Mantener también es progresar

No existe obligación de cambiar un estímulo que sigue siendo apropiado.

### F-PROG-004 — Regresar es una herramienta

Las regresiones forman parte normal del proceso.

### F-PROG-005 — El objetivo tiene prioridad sobre el ejercicio

Una tarea podrá sustituirse si otra permite desarrollar mejor la misma capacidad.

### F-PROG-006 — La carga es solo una variable

FORJA utilizará múltiples dimensiones de progresión.

### F-PROG-007 — La mínima dosis suficiente guía el volumen

No se añadirá trabajo sin una razón.

### F-PROG-008 — El contexto puede retrasar una progresión

Estar preparado no obliga a aumentar demanda en ese momento.

### F-PROG-009 — Las progresiones serán preferentemente interpretables

Cuando sea razonable se modificarán pocas variables simultáneamente.

### F-PROG-010 — Los niveles pertenecen a tareas

FORJA no etiquetará globalmente al deportista.

### F-PROG-011 — Las progresiones pueden ramificarse

No todas las capacidades seguirán una escalera lineal.

### F-PROG-012 — Cada ejercicio deberá explicar cómo progresar y regresar

La futura biblioteca almacenará decisiones, no solo descripciones.

### F-PROG-013 — La seguridad se evalúa antes de progresar

Dolor o señales relevantes tendrán prioridad sobre cualquier objetivo de carga.

### F-PROG-014 — La fatiga se interpreta respecto al objetivo

Su presencia puede justificar mantener, reducir o finalizar una tarea.

### F-PROG-015 — FORJA asistirá decisiones, no sustituirá al entrenador

La automatización futura deberá permitir interpretación profesional.

---

# 39. Qué significa esto para el entrenador

Antes de progresar cualquier tarea, FORJA propone siete preguntas:

> **1. ¿Qué objetivo tiene esta tarea?**

> **2. ¿El deportista la ejecuta con competencia suficiente?**

> **3. ¿La tolera bien?**

> **4. ¿El estímulo actual sigue siendo suficiente?**

> **5. ¿El contexto permite aumentar la demanda?**

> **6. ¿Qué variable sería la mejor para progresar?**

> **7. ¿Cómo sabremos si la decisión ha funcionado?**

Si no podemos responder la primera pregunta:

> no deberíamos progresar todavía.

---

# Ideas clave finales

Si solo recuerdas ocho ideas:

1. **Progresar no significa hacer ejercicios más difíciles.**
2. **Una progresión debe responder a un objetivo.**
3. **Competencia suficiente no significa perfección.**
4. **Mantener una tarea puede ser la mejor decisión.**
5. **Regresar temporalmente forma parte de progresar.**
6. **Carga, volumen, velocidad, rango, complejidad e incertidumbre son variables diferentes.**
7. **El nivel pertenece a la tarea, no a la persona.**
8. **FORJA no pregunta "¿qué ejercicio viene después?", sino "¿qué estímulo necesita después?".**
