# FORJA visual pack — EX-002

Paquete de trabajo con los prototipos visuales generados y aprobados conceptualmente.

## Contenido
- `exercises/ex-002/master/`: ilustración maestra conceptual (Nivel 1).
- `exercises/ex-002/web/`: infografía web (Nivel 2).
- `brand/prototypes/`: concepto de identidad FJ/FORJA y composición de ficha de sesión.
- `references/`: referencia adicional de composición visual.

## Importante
Los elementos FJ/FORJA incluidos dentro de imágenes rasterizadas son conceptos aprobados visualmente,
pero NO deben tratarse como logo master. El master de marca debe generarse como activo independiente
(preferentemente SVG + PNG transparente) antes de su uso sistemático.

La ficha Nivel 3 debe aislarse/generarse como recurso independiente; no debe recortarse del composite
y darse por definitiva sin revisión.
