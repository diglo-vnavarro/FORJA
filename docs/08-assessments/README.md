# Evaluación y seguimiento

Este módulo define las herramientas metodológicas y operativas para conocer el
punto de partida del joven deportista, orientar la toma de decisiones y valorar
su evolución a lo largo del tiempo.

Conforme a [MET-001](../03-methodology/initial-athlete-assessment.md), la evaluación
no busca calificar con una nota numérica ni emitir juicios globales («bueno» o «malo»),
sino responder a la pregunta fundamental:

> **¿Desde dónde empezamos y qué necesita este deportista ahora?**
