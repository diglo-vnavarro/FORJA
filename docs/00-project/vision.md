# Visión de FORJA

## Definición

FORJA es un sistema de conocimiento y toma de decisiones para el desarrollo físico de jóvenes deportistas.

## Propósito

Ayudar a entrenadores, familias y deportistas a tomar decisiones más seguras, coherentes y fundamentadas sobre el entrenamiento físico durante las etapas de crecimiento.

## Aspiración

Construir una metodología:

- basada en evidencia;
- comprensible;
- reutilizable;
- adaptable;
- versionada;
- abierta a revisión;
- orientada al desarrollo a largo plazo.

FORJA no pretende ofrecer una respuesta idéntica para todos los deportistas.

Pretende proporcionar criterios para elegir, adaptar y revisar la respuesta más adecuada en cada contexto.

## Principio rector

Toda decisión debe aumentar la probabilidad de que el joven deportista siga disfrutando, mejorando y practicando deporte a largo plazo.
