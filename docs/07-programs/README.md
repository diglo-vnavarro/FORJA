Este módulo define la organización temporal de estímulos de preparación física a lo largo de microciclos semanales integrados en el calendario deportivo real.

## Criterios metodológicos

1. **Prioridad del deporte principal**: FORJA no sustituye el entrenamiento del equipo, sino que modula los estímulos complementarios para maximizar disponibilidad y salud a largo plazo.
2. **Contexto antes que receta fija**: Las etiquetas de días (`MD-1`, `MD-2`) modulan el coste aceptable de fatiga, pero no obligan a una pauta invariable.
3. **Mínima dosis suficiente**: Mantener capacidad motriz en semanas congestionadas es un objetivo de éxito en la periodización formativa.
