# FORJA App Design System v1

Paquete único de integración para la aplicación FORJA.

Incluye:
- símbolo FORJA aprobado;
- wordmark FORJA en la última versión aceptada;
- lockup horizontal;
- 40 conceptos semánticos;
- Tabler Icons como base profesional;
- 3 iconos específicos FORJA;
- `currentColor` y tokens CSS;
- componente React `ForjaIcon`;
- `AGENTS.md` para Codex;
- instrucciones de integración y prompt de migración;
- licencia MIT de Tabler Icons.

Principio:
**geometría inmutable · color tematizable · iconografía semántica**
