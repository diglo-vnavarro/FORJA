# Activos de marca FORJA

Este directorio reserva la estructura para los masters definitivos de la
identidad FJ/FORJA.

## Componentes

- **Símbolo FJ:** identificador compacto de la marca.
- **Wordmark FORJA:** representación tipográfica del nombre.
- **Lockup horizontal:** composición conjunta del símbolo FJ y el wordmark
  FORJA.

## Uso previsto

El símbolo FJ podrá utilizarse de forma discreta en las camisetas de los
deportistas representados, conforme a VIS-002.

El wordmark FORJA se reserva principalmente para cabeceras, documentos,
interfaces y otros espacios editoriales.

El lockup horizontal se utilizará cuando símbolo y nombre deban aparecer como
una única composición de marca.
