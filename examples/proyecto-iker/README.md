# Proyecto Iker

Proyecto Iker es el primer caso práctico de aplicación de FORJA.

## Contexto inicial

El caso parte de un futbolista sub-14 que desea realizar una preparación física previa a la pretemporada.

La aplicación permitirá comprobar si los principios, evaluaciones, ejercicios y programas de FORJA pueden transformarse en un plan seguro, comprensible y reutilizable.

## Separación respecto a la metodología

Los datos personales concretos, observaciones individuales y decisiones específicas del caso permanecerán en esta carpeta.

Las conclusiones generalizables solo se incorporarán a la metodología después de su revisión.

## Estado

Pendiente de desarrollar cuando estén definidos los primeros fundamentos científicos y metodológicos.
