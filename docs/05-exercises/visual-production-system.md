# Sistema de producción visual de ejercicios FORJA

## Propósito

Definir un flujo repetible para transformar una ficha EX aprobada en:

1. ilustración maestra;
2. infografía web;
3. ficha rápida de sesión.

VIS-002 complementa [VIS-001](visual-standard.md): VIS-001 define el lenguaje visual y VIS-002 define cómo producirlo con consistencia, reutilización, trazabilidad y revisión.

---

# 1. Fuente única de verdad

La ficha EX es la fuente metodológica.

No se mantendrá otra versión independiente de:

- objetivo;
- patrón;
- capacidades;
- material;
- ejecución;
- consignas;
- competencia;
- errores;
- regresiones;
- progresiones;
- criterios de parada.

El brief visual selecciona información de la ficha.

No crea información nueva.

> **FICHA EX → BRIEF VISUAL → NIVEL 1 → NIVEL 2 / NIVEL 3**

---

# 2. Los tres niveles

## Nivel 1 — Ilustración maestra

Representa el ejercicio base mediante identidad, material, ejecución y fases relevantes.

Debe ser editorial, deportiva, limpia, semi-realista, profesional, con anatomía plausible, fondo limpio, material exacto y las fases estrictamente necesarias.

No muestra dosis, series, repeticiones, RPE, dificultad ni grandes bloques de texto.

## Nivel 2 — Infografía web

Explica rápidamente el ejercicio en web o aplicación reutilizando la ilustración y el lenguaje del Nivel 1.

Su jerarquía conceptual es:

1. cabecera;
2. identidad y objetivo;
3. ilustración y ejecución;
4. competencia;
5. «Modifica la tarea si...»;
6. «No corrijas automáticamente»;
7. adaptación;
8. variables de prescripción;
9. ejemplo contextual cuando exista.

## Nivel 3 — Ficha rápida de sesión

Permite consultar la tarea en aproximadamente cinco segundos en móvil, tableta, PDF, impresión o campo.

Utiliza una simplificación vectorial coherente con el Nivel 1.

Contiene solo la identidad mínima, miniatura, entre dos y cuatro consignas y la prescripción contextual de la sesión.

---

# 3. Contenido estable y contextual

## Estable

Procede de la ficha EX:

- identificador y nombre;
- objetivo;
- patrón y capacidades;
- material;
- ejecución;
- competencia;
- consignas;
- relaciones.

## Contextual

Procede de la sesión:

- variante elegida;
- series;
- repeticiones, distancia o tiempo;
- carga;
- recuperación;
- RPE o RIR objetivo;
- criterio de parada específico.

La dosis contextual no pertenece al ejercicio base.

---

# 4. Identidad de marca

La dirección conceptual aprobada combina:

- símbolo compacto FJ;
- wordmark FORJA.

El master deberá existir como activo independiente, preferentemente con:

- SVG maestro;
- PNG o WebP derivados;
- versión símbolo;
- versión símbolo + FORJA.

El master está pendiente.

No se reconstruirá desde capturas, infografías ni imágenes rasterizadas.

## Logo en ropa

El símbolo FJ podrá aparecer en la camiseta del deportista en Nivel 1 y Nivel 3 cuando exista el master aprobado.

Será pequeño, legible, estable, no protagonista y no se deformará.

El wordmark FORJA se reserva principalmente para cabeceras, pies, interfaz y documentación.

---

# 5. Sistema de personaje

El deportista será juvenil o adolescente, genérico, no identificable, atlético sin estética culturista, con anatomía plausible, proporciones naturales, ropa neutra y zapatillas deportivas.

Debe transmitir:

> joven deportista.

No adulto fitness profesional ni personaje infantil.

La biblioteca podrá mostrar chicos, chicas y diferentes fenotipos, conservando edad visual aproximada, lenguaje gráfico, ropa conceptual, gama visual, luz y proporciones.

La diversidad no producirá estilos independientes.

# 6. Brief visual

Cada ejercicio con ficha EX completa tendrá un brief en [visual-briefs](visual-briefs/).

El brief no duplica la ficha: registra únicamente decisiones necesarias para representarla.

## Estructura

### Identidad

- ID;
- nombre.

### Fuente

- ruta a la ficha EX.

### Nivel 1

- fases;
- perspectiva;
- material;
- elementos esenciales;
- elementos que no deben convertirse en reglas;
- texto alternativo provisional.

### Nivel 2

- cabecera;
- pasos resumidos;
- competencia seleccionada;
- errores y criterios seleccionados;
- variaciones que no deben corregirse automáticamente;
- adaptaciones;
- variables de prescripción;
- ejemplo contextual.

### Nivel 3

- miniatura;
- entre dos y cuatro consignas candidatas;
- campos contextuales admitidos.

### Revisión

- checklist específico.

Los ejercicios sin ficha completa no reciben brief definitivo.

# 7. Infografía web

## Cabecera

Puede mostrar ID, nombre, logo, objetivo, patrón, capacidad principal, atributo relevante y material.

No mostrará nivel, puntuación, edad universal ni ranking.

## Ejecución

Se seleccionarán entre tres y cinco pasos cortos, observables y fieles a la ficha.

## Competencia

Se seleccionarán aproximadamente entre cuatro y seis indicadores prioritarios.

## Modificar

«Modifica la tarea si...» deriva exclusivamente de errores relevantes, criterios de parada, motivos para no elegir y seguridad.

No se utilizará «incorrecto» como juicio visual absoluto.

## No corregir automáticamente

Deriva conservadoramente del campo homónimo de la ficha.

## Adaptar

Mostrará ramas para hacer más accesible o cambiar la demanda.

No representará una escalera de fácil a difícil.

## Prescripción

Mostrará variables de prescripción y, opcionalmente, un ejemplo contextual identificado como no universal.

---

# 8. Ficha rápida de sesión

## Bloque estable

- ID;
- nombre;
- miniatura;
- entre dos y cuatro consignas.

## Bloque contextual

- variante;
- series;
- repeticiones, distancia o tiempo;
- carga;
- recuperación;
- RPE o RIR;
- criterio de parada.

Podrá mostrar una regresión o progresión inmediata cuando aporte valor.

Ejemplo conceptual para EX-002:

> 6 repeticiones × 3 series · RIR 2–3 · 90 s

Estos valores no son una prescripción permanente.

# 9. EX-002 como referencia

[EX-002 — Sentadilla goblet](library/ex-002-goblet-squat.md) es la referencia visual inicial.

- Nivel 1: validación conceptual completada; activo no almacenado.
- Nivel 2: validación conceptual completada; activo no almacenado.
- Nivel 3: siguiente prototipo.

La cabecera conceptual contiene EX-002, nombre, fuerza, dominante de rodilla, bilateral, carga externa y mancuerna o kettlebell.

La ilustración contiene inicio y descenso.

Las claves seleccionadas son carga cerca, apoyo estable, descenso controlado y empujar el suelo.

La competencia, modificaciones, variaciones aceptables, adaptaciones, variables y ejemplo contextual se extraen exclusivamente de la ficha EX-002.

No existe una única progresión obligatoria.

assets/exercises/ex-002/

├── web/

Naming recomendado:

- `ex-002-goblet-squat-master-01.webp`;
- `ex-002-goblet-squat-master-02.webp`;
- `ex-002-goblet-squat-web.webp`;

- `ex-022-acceleration-stop-zone-diagram.svg`.

El formato no es obligatorio hasta disponer de pipeline. El naming sí debe ser predecible.

Git conserva el historial; no se incorporarán versiones al nombre salvo necesidad futura.

# 11. Proceso por ejercicio

1. Ficha EX utilizable.
2. Crear brief visual.
3. Revisar brief.
4. Generar Nivel 1.
5. Revisar Nivel 1.
6. Crear Nivel 2.
7. Revisar Nivel 2.
8. Crear Nivel 3.
9. Revisar Nivel 3.
10. Marcar el paquete visual aprobado.

No se generarán los tres niveles simultáneamente sin revisar Nivel 1.

---

# 12. Checklist Nivel 1

- coincide con el ejercicio;
- material correcto;
- número correcto de extremidades;
- manos y pies plausibles;
- apoyos correctos;
- logo correcto;
- postura compatible con la ficha;
- fases claras;
- ausencia de reglas nuevas;
- fondo limpio;
- personaje apropiado;
- ausencia de marcas externas.

---

# 13. Checklist Nivel 2

- todo el texto deriva de la ficha;
- no inventa niveles, dosis ni criterios;
- jerarquía visual clara;
- ilustración correcta;
- competencia visible;
- adaptación representada como ramas;
- ejemplo marcado como contextual;
- aviso de receta no universal cuando corresponda;
- logo correcto;
- lectura web clara.

---

# 14. Checklist Nivel 3

- legible a tamaño pequeño;
- ilustración simplificada coherente;
- entre dos y cuatro consignas;
- dosis claramente contextual;
- recuperación visible cuando sea relevante;
- criterio de parada prioritario;
- ausencia de texto innecesario;
- logo discreto;
- utilidad en campo.

# 17. Decisiones FORJA

### F-VPROD-001 — Una ficha EX alimenta todas las representaciones visuales

### F-VPROD-002 — Cada ejercicio tendrá un brief visual antes de producir activos

### F-VPROD-003 — El brief selecciona información; no crea metodología

### F-VPROD-004 — Nivel 1 debe aprobarse antes de escalar a Nivel 2 y Nivel 3

### F-VPROD-005 — El Nivel 2 reutiliza la identidad visual del Nivel 1

### F-VPROD-006 — El Nivel 3 simplifica, pero no reinterpreta el ejercicio

### F-VPROD-007 — El contenido contextual de sesión no pertenece al ejercicio base

### F-VPROD-008 — El logo FJ podrá aparecer discretamente en la ropa

### F-VPROD-009 — El master del logo será un activo independiente

### F-VPROD-010 — No se reconstruirá el logo desde imágenes rasterizadas

### F-VPROD-011 — Todos los activos deberán ser revisados humanamente

### F-VPROD-012 — La existencia conceptual de un prototipo no equivale a asset almacenado

### F-VPROD-013 — Los ejercicios sin ficha completa no reciben brief definitivo

### F-VPROD-014 — Los activos se producirán por lotes y con revisión intermedia

### F-VPROD-015 — La identidad visual debe permanecer coherente con diversidad de personajes

### F-VPROD-016 — Los recursos visuales nunca podrán introducir niveles absolutos de dificultad

### F-VPROD-017 — El sistema visual debe funcionar en web, móvil, documentos y sesión

### F-VPROD-018 — Git conserva la trazabilidad de cambios visuales
